# HuggingMath transfer

The optional `hub` command transfers frozen results to HuggingMath. Read `hub --help`
through the run's generated `.scratch/theoremos-help.md` tool entry for exact syntax.
Use it when a transfer is requested; ordinary research has no background Hub upload.

Export a finished run using its saved state, final result and explicit attribution.
The exporter preserves all original targets, committed source/support/environment
bytes and historical evidence. Selected independent declarations are provenance;
they do not establish completion of the original problem. Review source rights
before choosing the files to transfer; unspecified rights remain unknown.

Platform login and import journals belong outside the research worktree. Use an
operator-provided session profile; keep credentials out of notes, prompts and bundles.
Preview stores a plan and retry key. Apply uses that same journal and creates private
drafts. After a lost response, retry the saved journal; a stale plan needs a new preview.

An external successful check remains source evidence. Imported proofs have Hub
verification `not_run`; canonical review, publication and library admission are
separate. This command has no `/v1` problem retrieval, native Pack installer or Hub
verification service because those interfaces are still draft.
