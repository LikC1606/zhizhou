# MaAS 写作参考

在撰写多智能体架构搜索、按任务动态配置推理流程或成本感知路由相关的论文与技术报告时，将这篇论文用作写作参考。

Guibin Zhang, Luyang Niu, Junfeng Fang, Kun Wang, Lei Bai, and Xiang Wang. *Multi-agent Architecture Search via Agentic Supernet*. ICML 2025, PMLR 267, pp. 75834–75852. [PMLR 正式发表页](https://proceedings.mlr.press/v267/zhang25bi.html) · [正式版 PDF](../../sources/papers/zhang2025-maas.pdf)

## 可借鉴的写法

- **引言先写固定流程遇到的具体问题。** §1 与 Figure 1 把任务难度和所需工具的差异摆到读者面前，再引出按查询采样架构。可以借鉴这一顺序，用自己任务中的两三个例子说明固定流程在哪些条件下会多花资源或漏掉必要步骤。
- **方法图把概念和执行过程接起来。** Figure 1 先介绍可组合的算子和不同查询走出的路径，Figure 2 再展示采样、执行、反馈和更新。§3.2–3.3 适合定位查询条件采样、提前退出和成本目标，复用这套叙述时应换成自己系统的术语、组件和流程。
- **结果把质量与开销放在同一个对照里。** Table 3 将训练和推理分开报告，分别列出 token 数、API 费用和耗时，再并列准确率。作为原文中的具体例子，在论文选取的 MATH 子集上，MaAS 与 AFlow 的准确率分别为 51.82% 和 51.28%，表中推理 API 费用分别为 0.42 和 1.66 美元。引用时保留评测子集、对照方法与费用口径。
- **案例展示动态路由究竟做了什么。** §4.4 的 Figures 5–6 用算子概率和实际执行路径解释何时提前停止、何时增加算子。写自己的案例时，可以用不同类型或难度的输入对照具体路径。

在相关工作中，可引用 MaAS 作为按查询采样多智能体架构并考虑推理成本的先例。引用具体增益时，以正式 PDF 中对应表格、对照与设置为准。PMLR 网页摘要和正式 PDF 摘要的最高提升数字不同，宜写成可定位的单项比较。
